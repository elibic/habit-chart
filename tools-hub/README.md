# 🧰 מרכז הכלים

דף אחד שמרכז את כל הכלים שנבנו כאן — קישור, אייקון והסבר קצר לכל אחד — ולידו
דף עריכה שמאפשר להוסיף כלי חדש מהדפדפן, בלי לגעת בקוד ובלי מחשב מפתחים.

הדף כולו סטטי: שלושה קבצים ואין שרת. מקור האמת היחיד הוא `tools.json`, ודף
העריכה פשוט כותב אליו בחזרה דרך ה-API של גיטהאב.

## הקבצים

| קובץ | מה הוא |
| --- | --- |
| `index.html` | דף הכלים עצמו — כרטיסים, חיפוש וסינון לפי קטגוריה |
| `edit.html` | דף העריכה, מאחורי מפתח אישי |
| `tools.json` | הרשימה. זה כל המידע שיש באתר |
| `config.js` | שם הריפו והענף. המקום היחיד שצריך לשנות אם הריפו זז |
| `style.css` | עיצוב לשני הדפים, מצב בהיר וכהה |

## הפעלה ראשונה

1. **פרסום.** בגיטהאב: `Settings → Pages → Build and deployment → Deploy from a
   branch`, ולבחור `main` ו-`/ (root)`. תוך דקה הדף עולה בכתובת
   `https://<שם המשתמש>.github.io/tools/`.
2. **מפתח לעריכה.** ב-[Fine-grained tokens](https://github.com/settings/personal-access-tokens/new):
   `Only select repositories` → הריפו הזה, ותחת `Repository permissions` לתת
   ל-`Contents` את הערך `Read and write`. שום הרשאה אחרת לא נדרשת.
3. להיכנס ל-`/edit.html`, להדביק את המפתח פעם אחת — הוא נשמר בדפדפן — ולערוך.

## איך מוסיפים כלי חדש

דרך דף העריכה: `+ כלי חדש`, ממלאים שם, שורת הסבר, כתובת וקטגוריה, ולוחצים
שמירה. השמירה היא קומיט אמיתי ל-`tools.json`, כך שיש היסטוריה של כל שינוי
ואפשר לחזור אחורה.

מי שמעדיף לערוך ידנית יכול פשוט לערוך את `tools.json`. שדות של כלי:

| שדה | מה הוא עושה |
| --- | --- |
| `name`, `tagline`, `description` | שם, שורה אחת, והסבר |
| `url` | הקישור לכלי. כלי בלי כתובת מוצג כ״בבנייה״ ואינו ניתן ללחיצה |
| `repo` | קישור לקוד, לא חובה |
| `icon` | אימוג׳י אחד |
| `category` | הופך אוטומטית לכפתור סינון בראש הדף |
| `status` | `live` או `wip` |
| `hidden` | `true` מוציא את הכלי מהדף בלי למחוק אותו |

## למה זה בנוי ככה

**המידע נפרד מהעיצוב.** אין רשימת כלים בתוך ה-HTML, ולכן הוספת כלי אף פעם לא
דורשת נגיעה בקוד — לא ידנית ולא מדף העריכה.

**אין שרת ואין סיסמה משלנו.** ההזדהות היא של גיטהאב עצמו: מפתח אישי שמוגבל
לריפו אחד ולהרשאה אחת. אין משתמשים לנהל, אין מה לדלוף מהאתר, והאתר נשאר קובץ
סטטי שמתארח בחינם.

**הדף מתעדכן מיד.** דף הכלים מנסה קודם למשוך את `tools.json` דרך ה-API — שם
הוא מעודכן שניות אחרי השמירה — ואם זה לא זמין תוך שלוש שניות הוא נופל לקובץ
שפורסם באתר. כך עריכה נראית מיד, וגם ללא רשת תקינה הדף עדיין עובד.
