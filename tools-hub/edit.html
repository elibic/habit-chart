עריכת הכלים

מוסיפים כלי, כותבים הסבר, שומרים — והדף מתעדכן.

כניסה

העריכה נשמרת ישירות לריפו בגיטהאב, ולכן היא דורשת מפתח אישי שלך. המפתח נשמר רק בדפדפן הזה.

איך מייצרים מפתח, פעם אחת: נכנסים ל־GitHub → Fine-grained tokens, בוחרים Only select repositories ומסמנים את הריפו של הדף הזה, ותחת Repository permissions נותנים ל־Contents את הערך Read and write. זה כל מה שצריך — אין טעם לתת יותר.
